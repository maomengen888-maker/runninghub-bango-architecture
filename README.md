# Bango Agent Product Architecture

基于 RunningHub Bango Agent 页面证据完成的产品架构拆解，覆盖从自然语言创作需求到角色设计信息完成的用户旅程。

## 项目目标

把页面中可观察到的功能、状态和 Agent 协作关系，整理为一张可评审的六层产品架构图，同时避免把页面之外的推断伪装成产品事实。

## 六层架构

1. **用户层**：自然语言输入、参数选择、专业 Agent 群聊、节点画布与结果管理
2. **应用层**：艺术总监、编剧、角色设计师及创作应用
3. **平台层**：Agent 编排、创作工具服务与项目全局上下文
4. **基座层**：工作流运行时、模型与资产基座、治理与运维
5. **模型层**：文本规划、视觉生成、视频与音频能力
6. **数据层**：项目数据、创作资产、知识与配置

## 证据表达

架构图使用四种视觉标记：

- 页面事实
- 合理推断
- 建议设计
- 尚未确认

这种表达方式让评审者能快速判断哪些结论有直接证据，哪些仍需要访谈、测试或技术验证。

## 关键产品判断

- 多 Agent 协作需要统一的项目上下文与阶段确认机制
- 节点画布不仅是展示层，还涉及依赖调度、状态同步与上游修改后的失效传播
- “角色信息完成”不等于立绘资产完成，产品状态应避免把中间结果表达成最终资产
- 模型选择、计费、场景、分镜、视频与音频能力在当前证据范围内仍属待确认项
